# Beyond the Depths

[![Play on Itch.io](https://img.shields.io/badge/Itch.io-Play%20Now-orange?style=for-the-badge&logo=itch.io)](https://ozald.itch.io/beyond-the-depths)
[![Unity](https://img.shields.io/badge/Unity-2022.3LTS-black?style=for-the-badge&logo=unity)](https://unity.com/)

A short, fast-paced 2D roguelike game developed for **INIT Build Spring 2026**. A mysterious spire appears with seemingly no end, and it is your job to go beyond the depths and face what's inside.
Legends say a gatekeeper appears to stop your descent three levels deep... can you make it to the end?

## Controls
WASD / Arrow Keys -- Movement<br>
Left-click -- Attack<br>
E -- Interact<br>
Q -- Swap Weapons<br>

## Tech Stack
**Engine:** Unity<br>
**Art:** Asesprite<br>
**Audio:** FL Studio & FMOD<br>

## Known Issues
If the game is stuck on a black screen, chances are you are using a browser such as Firefox. I recommend switching to Google Chrome to get the best experience.
